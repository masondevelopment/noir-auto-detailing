# NOIR Auto Detailing

Premium landing page concept for a fictional Miami auto detailing studio.

## Stack

- React + Vite + TypeScript
- Tailwind CSS for the utility foundation
- Framer Motion for restrained reveal and state transitions
- Lucide React for interface icons

## Run locally

```bash
npm install
npm run dev
```

The production build and type-aware lint check are:

```bash
npm run build
npm run lint
```

## Notes

All imagery is loaded from Unsplash with responsive sizing parameters and `loading="lazy"` outside the hero. The contact form is intentionally frontend-only: it validates required fields and shows an in-page success state without transmitting data.
